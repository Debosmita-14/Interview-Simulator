🚀 DEPLOYMENT OPTIONS
═══════════════════════════════════════════════════════════════════════════════

OPTION 1: Vercel Deployment (Recommended - NO Node.js needed)
  1. Push code to GitHub
  2. Go to vercel.com → New Project
  3. Select your GitHub repo
  4. Add environment variables
  5. Deploy (automatic)
  └─ Your app is LIVE in 5 minutes!

OPTION 2: Local Development (Need Node.js v16+)
  1. Install Node.js from nodejs.org
  2. Run setup.bat
  3. Start backend: npm run dev (backend folder)
  4. Start frontend: npm start (frontend folder)
  5. Visit http://localhost:3000

For Vercel Deployment:
  ☐ Push code to GitHub (git push)
  ☐ Create Vercel account at vercel.com
  ☐ Get MongoDB URI from mongodb.com/cloud/atlas (free)
  ☐ Get Claude API key from console.anthropic.com (free trial)
  ☐ Configure environment variables in Vercel
  ☐ Click Deploy
  ☐ Your app is LIVE!

For Local Development:
  ☐ Install Node.js v16+
  ☐ Update backend/.env with API keys
  ☐ Run: npm install (in backend and frontend)
  ☐ Run: npm run dev (backend in Terminal 1)
  ☐ Run: npm start (frontend in Terminal 2)
  ☐ Visit http://localhost:3000
