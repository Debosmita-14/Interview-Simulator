OPTION 1: Automated Setup (Recommended)
──────────────────────────────────────
Windows:
  1. Double-click: setup.bat
  2. Answer prompts
  3. Add API keys to backend/.env

Mac/Linux:
  1. Run: bash setup.sh
  2. Answer prompts
  3. Add API keys to backend/.env

OPTION 2: Quick Manual Setup (5 minutes)
───────────────────────────────────────
1. Terminal 1 (Backend):
   $ cd backend
   $ npm install
   $ # Add CLAUDE_API_KEY to .env
   $ npm run dev

2. Terminal 2 (Frontend):
   $ cd frontend
   $ npm install
   $ npm start

3. Browser:
   → Open http://localhost:3000

OPTION 3: Docker (Production)
────────────────────────────
$ docker-compose up
→ Open http://localhost
